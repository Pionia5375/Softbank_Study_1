## 예시 레코드 (킥오프 전에 Jeong이 1건 넣어 둠 — 형식 시범)

**D-00 팀 노션 구조: DB 3개(Meetings/Decisions/Tasks) + Design Doc 1페이지**
- 선택: Meetings·Decisions·Tasks를 DB로 분리, 심사용 문서는 Design Doc 한 페이지.
- 대안: ① 작년 Yellow식(회의록 페이지 + Docs 9개 나열) — 결정·진행이 본문에 묻힘. ② DB 1개에 종류 속성 — 필터가 복잡해져 안 쓰게 됨.
- 이유: 제출물이 "작업 중 메모 + 대안·이유 회의록"이고 발표가 "설계 문서 2분"이라, 결정이 따로 모여 있고 설계 문서가 한 페이지여야 함.
- 측정값: 미측정 — 11/3에 "회의 후 15분 안에 노션 갱신이 끝나는가"로 확인.
- 심사항목: 팀 개발.
