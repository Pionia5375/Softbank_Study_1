# 📅 Meetings DB

작년 Yellow의 "Meeting Schedules 표 + Meeting Notes 목록"을 DB 하나로 합친 것. 캘린더 뷰가 일정표, 리스트 뷰가 회의록 목록.

## 속성

| 속성 | 타입 | 선택지 / 메모 |
|---|---|---|
| 제목 | Title | `10/30 킥오프`, `10/31 #1 아키텍처 확정` 처럼 날짜+주제 |
| 날짜 | Date (시간 포함) | 캘린더 뷰 기준 |
| 종류 | Select | 킥오프 / 정기 / 긴급 / 중간보고 / 최종발표 |
| 참석자 | Person (다중) | |
| 허들 링크 | URL | 슬랙 허들 녹음 또는 AI 요약 메시지 퍼머링크 |
| 결정 | Relation → Decisions | 양방향 |
| 액션 | Relation → Tasks | 양방향 |
| 상태 | Select | 예정 / 완료 |

## 뷰

- **캘린더** (날짜 기준) — 홈에 임베드. 작년의 일정표 대체.
- **리스트** (날짜 내림차순, 종류·참석자 표시) — 회의록 목록.
