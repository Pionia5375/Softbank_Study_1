## 역할 분배 기준 (킥오프에서 합의)

- 파트는 **주제 공개 후** 아키텍처에서 나온 컴포넌트 단위로 나눈다. 킥오프 날은 "잘하는 것 / 하고 싶은 것 / 시간"만 적는다.
- 한 파트에 주담당 1 + 부담당 1 (주담당이 막히면 부담당이 같이 본다).
- 시간이 많은 사람이 **파트 간 연결(인터페이스·통합·데모)**을 맡는다.
- 역할은 바꿀 수 있다. 바꾸면 Decisions에 1줄 남긴다.

## 소통 약속

- 질문·논의: 슬랙 채널 스레드. 답은 2시간 안에 (못 하면 이모지라도).

## 2. 레포 · 브랜치 · PR 규칙

- 전체 규칙: 레포 `CONTRIBUTING.md` (출처: `starter-pack/github/02-strategy.md`)
- 한 줄 요약: 모노레포, `main` 하나 + squash, PR은 작게·하루 안에 머지, 리뷰 1명.
- 이슈 1 = PR 1. 이슈 첫 줄에 노션 Task URL, PR 첫 줄에 `Closes #N`. GitHub Projects·Wiki 안 씀.
- 정적 분석·린트: CI(`.github/workflows/ci.yml`)가 돌림. 정책 문서 따로 없음.
