# ✅ Tasks DB

"모든 진행 상황을 확인할 수 있을 것"을 담당하는 보드. 기능 단위(15~30개)만. 코드 수준 세부는 GitHub 이슈·PR에 두고 링크만 건다.

## 속성

| 속성 | 타입 | 선택지 / 메모 |
|---|---|---|
| 제목 | Title | 동사로. `함수 배포 API POST /functions 구현` |
| 담당 | Person | 1명. 둘이면 쪼갠다 |
| 상태 | Select | Todo / Doing / Review / Done / Blocked |
| 파트 | Select | 인프라 / 배포 / 백엔드 / 프론트 / 관측 / AI / 문서·데모 |
| 우선순위 | Select | Must / Should / Could |
| 마감 | Date | |
| 링크 | URL | GitHub 이슈 또는 PR |
| 회의 | Relation → Meetings | 어느 회의에서 나왔나 |
| 메모 | Text | 막힌 이유 등 한 줄 |

## 뷰

- **보드 (상태별 그룹)** — 홈에 임베드. 카드에 담당·파트·우선순위·마감 표시.
- **담당별 테이블** — 회의 때 한 사람씩 훑기.
- **Must만** 필터 — 11/5 이후는 이 뷰만 본다.

## 상태 규칙

- Todo → Doing: 시작할 때 본인이.
- Doing → Review: PR 올릴 때. 링크 속성에 PR.
- Review → Done: 머지될 때.
- Blocked: 30분 넘게 막히면. 메모에 "무엇·뭘 해봤나". 슬랙에도 올린다.
- 마감 지난 Todo는 회의에서 Could로 내리거나 지운다. 보드에 죽은 카드를 남기지 않는다.
